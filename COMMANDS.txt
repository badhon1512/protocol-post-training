SOOFI POST-TRAINING COMMANDS
============================

Run these commands from the project root:
C:\Job Search\PHD\SOOFI\Post training


1. SETUP
--------

Create/synchronize the uv environment and install dependencies:

uv sync

Check PyTorch, CUDA, and the GPU:

uv run python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA available:', torch.cuda.is_available()); print('CUDA version:', torch.version.cuda); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"

Show the options supported by any script:

uv run python -m scripts.train --help
uv run python -m scripts.generate_test --help
uv run python -m scripts.evaluate --help


2. TRAIN
--------

Defaults used by scripts.train:
- model: gemma
- model checkpoint: google/gemma-3-270m
- qwen checkpoint: Qwen/Qwen3-8B
- data: data/dolly_soofi_600_strict.jsonl
- learning rate: 5e-6
- max grad norm: 0.3

Normal training with Hugging Face SFTTrainer:

uv run python -m scripts.train --trainer hf --training-mode normal --output-dir outputs/gemma-hf-normal-lora

Normal training with the custom trainer:

uv run python -m scripts.train --trainer custom --training-mode normal --output-dir outputs/gemma-custom-normal-lora

Curriculum training with Hugging Face SFTTrainer:

uv run python -m scripts.train --trainer hf --training-mode curriculum --output-dir outputs/gemma-hf-curriculum-lora

Normal Hugging Face SFTTrainer with W&B:

uv run python -m scripts.train --trainer hf --training-mode normal --output-dir outputs/gemma-hf-normal-lora --report-to wandb --wandb-project soofi-post-training --run-name gemma-normal-sft

Curriculum Hugging Face SFTTrainer with W&B:

uv run python -m scripts.train --trainer hf --training-mode curriculum --output-dir outputs/gemma-hf-curriculum-lora --report-to wandb --wandb-project soofi-post-training --run-name gemma-curriculum-sft

Qwen3-8B with the Hugging Face SFT trainer and LoRA:

uv run python -m scripts.train --model qwen --trainer hf --training-mode normal --output-dir outputs/qwen3-8b-hf-normal-lora

Qwen3-8B curriculum training with Hugging Face SFTTrainer:

uv run python -m scripts.train --model qwen --trainer hf --training-mode curriculum --output-dir outputs/qwen3-8b-hf-curriculum-lora

Qwen3-8B with the custom trainer and LoRA:

uv run python -m scripts.train --model qwen --trainer custom --training-mode normal --output-dir outputs/qwen3-8b-custom-normal-lora

Example with explicit training settings:

uv run python -m scripts.train --model gemma --trainer custom --model-name google/gemma-3-270m --output-dir outputs/gemma-custom-lora --epochs 3 --learning-rate 2e-5 --train-batch-size 1 --val-batch-size 1 --gradient-accumulation-steps 8 --max-length 1024


3. GENERATE THE TEST RESPONSES
------------------------------

Generate a prompted zero-shot baseline from the original, untrained Gemma model
(no checkpoint from outputs/ and no LoRA adapter):

uv run python -m scripts.generate_test --model gemma --checkpoint google/gemma-3-270m --system-prompt-file data/SOOFI_PROTOCOL_PROMPT.md --data-path data/soofi_1000.json --output-path results/gemma-3-270m_prompted_baseline_generations.json --batch-size 4 --max-new-tokens 256

Generate with the custom Gemma checkpoint:

uv run python -m scripts.generate_test --model gemma --checkpoint outputs/gemma-custom-lora --data-path data/soofi_1000.json --output-path results/gemma-custom-lora_test_generations.json --batch-size 1 --max-new-tokens 256

Generate with the Hugging Face Gemma checkpoint:

uv run python -m scripts.generate_test --model gemma --checkpoint outputs/gemma-hf-lora --data-path data/soofi_1000.json --output-path results/gemma-hf-lora_test_generations.json --batch-size 1 --max-new-tokens 256

Generate with a Qwen checkpoint:

uv run python -m scripts.generate_test --model qwen --checkpoint outputs/qwen3-8b-hf-normal-lora --data-path data/dolly_soofi_600_strict.jsonl --output-path results/qwen3-8b-hf-normal-lora_test_generations.json --batch-size 4 --max-new-tokens 256

Optional sampled generation (the commands above use deterministic decoding):

uv run python -m scripts.generate_test --model gemma --checkpoint outputs/gemma-custom-lora --output-path results/gemma-custom-lora_sampled_generations.json --sample --temperature 0.7


4. EVALUATE
-----------

Evaluate the prompted base-model baseline:

uv run python -m scripts.evaluate --input-path results/gemma-3-270m_prompted_baseline_generations.json --output-path results/gemma-3-270m_prompted_baseline_evaluation.json --bertscore-batch-size 8

Evaluate the custom Gemma test responses:

uv run python -m scripts.evaluate --input-path results/gemma-custom-lora_test_generations.json

Evaluate the Hugging Face Gemma test responses:

uv run python -m scripts.evaluate --input-path results/gemma-hf-lora_test_generations.json

Evaluate the Qwen test responses:

uv run python -m scripts.evaluate --input-path results/qwen3-8b-hf-normal-lora_test_generations.json

Example with every evaluation option specified:

uv run python -m scripts.evaluate --input-path results/gemma-custom-lora_test_generations.json --output-path results/gemma-custom-lora_test_evaluation.json --quality-threshold 0.35 --bertscore-model xlm-roberta-base --bertscore-batch-size 8

The evaluator reports:
- Protocol score and complete protocol pass rate
- Existing lexical reference similarity
- Multilingual BERTScore F1
- BLEU
- Lexical quality pass rate


5. NORMAL WORKFLOW
------------------

Run these three commands in order:

uv run python -m scripts.train --model gemma --trainer custom --model-name google/gemma-3-270m --output-dir outputs/gemma-custom-lora

uv run python -m scripts.generate_test --model gemma --checkpoint outputs/gemma-custom-lora --output-path results/gemma-custom-lora_test_generations.json

uv run python -m scripts.evaluate --input-path results/gemma-custom-lora_test_generations.json --bertscore-batch-size 8


6. GRPO TRAINING
----------------

Continue from the supervised Gemma LoRA checkpoint with protocol-aware GRPO:

uv run python -m scripts.train_grpo --model gemma --checkpoint outputs/gemma-custom-lora --data-path data/soofi_1000.json --output-dir outputs/gemma-grpo-lora --epochs 1 --train-batch-size 1 --num-generations 4 --max-completion-length 256 --beta 0.04

One-step smoke test before committing to the full run:

uv run python -m scripts.train_grpo --model gemma --checkpoint outputs/gemma-custom-lora --data-path data/soofi_1000.json --output-dir outputs/gemma-grpo-smoke --max-train-samples 4 --max-steps 1 --train-batch-size 1 --num-generations 2 --max-completion-length 64

For the 8 GB GPU, keep train-batch-size at 1. GRPO generates four candidate
responses for each prompt and rewards protocol compliance plus reference quality.

Generate and evaluate the GRPO checkpoint:

uv run python -m scripts.generate_test --model gemma --checkpoint outputs/gemma-grpo-lora --output-path results/gemma-grpo-lora_test_generations.json --batch-size 1 --max-new-tokens 256

uv run python -m scripts.evaluate --input-path results/gemma-grpo-lora_test_generations.json --bertscore-batch-size 8

Audit generated dataset samples against prompt triggers and response rules:

uv run python -m scripts.audit_dataset --input data/dolly_soofi_1000.jsonl --output results/dataset_audit.json

Clean generated dataset with safe deterministic repairs and keep only passing rows:

uv run python -m scripts.clean_dataset --input data/dolly_soofi_1000.jsonl --output data/dolly_soofi_1000_clean.jsonl --report results/dataset_cleaning_report.json

Audit cleaned dataset:

uv run python -m scripts.audit_dataset --input data/dolly_soofi_1000_clean.jsonl --output results/dataset_audit_clean.json


7. BUILD THE 1K MULTILINGUAL DOLLY + SOOFI DATASET
-------------------------------------

Download Dolly and create/check the manifest without API spending:

uv run python -m scripts.plan_dataset_distribution

Preview the first complete LLM input without making an API call:

uv run python -m scripts.preview_dataset_prompt

uv run python -m scripts.build_dolly_protocol_dataset --prepare-only

After adding OPENAI_API_KEY to .env, generate with OpenAI (resumable):

uv run python -m scripts.build_dolly_protocol_dataset --provider openai --model gpt-5.4-mini

After adding DEEPSEEK_API_KEY to .env, generate with DeepSeek (resumable):

uv run python -m scripts.build_dolly_protocol_dataset --provider deepseek --model deepseek-v4-flash --concurrency 5

Generate only 200 new accepted samples:

uv run python -m scripts.build_dolly_protocol_dataset --provider deepseek --model deepseek-v4-flash --limit 200 --concurrency 5

Generate without rule-validation gating, then audit later:

uv run python -m scripts.build_dolly_protocol_dataset --provider deepseek --model deepseek-v4-flash --limit 200 --concurrency 5 --no-validate

Small clean test run:

uv run python -m scripts.build_dolly_protocol_dataset --provider deepseek --model deepseek-v4-flash --limit 10 --concurrency 5 --fresh

Note: normal runs preserve compatible completed rows from data/dolly_soofi_1500_provenance.jsonl when the new 1K output is empty. Do not use --fresh unless you intentionally want a clean archived restart.
